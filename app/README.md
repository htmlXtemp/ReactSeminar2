Устно: memo сравнивает props по ссылке. Если передать в карточку функцию, созданную заново при каждом рендере родителя, ссылка меняется — и memo считает prop новым, поэтому перерисовывает карточку. useCallback сохраняет ту же ссылку между рендерами, и тогда мемоизация начинает работать.
